# Ответы на контрольные вопросы

**1. Когда PHP вызывает автозагрузчик и что будет, если файл не найден?**
Автозагрузчик вызывается в момент первого обращения к неизвестному классу (`new`, статический вызов, `extends`, `instanceof` с загрузкой и т. п.). PHP по очереди вызывает все функции, зарегистрированные через `spl_autoload_register()`. Если после этого класс всё ещё не объявлен, выбрасывается ошибка `Error: Class "..." not found`.

**2. Преимущество `spl_autoload_register()` перед `__autoload()`?**
`__autoload()` — одна-единственная функция на всё приложение, и она удалена в PHP 8.0. `spl_autoload_register()` позволяет зарегистрировать несколько автозагрузчиков (очередь), в том числе анонимные функции и методы классов; это даёт возможность подключать сторонние библиотеки (например, Composer) вместе с собственным кодом без конфликтов.

**3. Чем абстрактный класс отличается от интерфейса? Когда что выбрать?**
Интерфейс описывает только сигнатуры методов (и константы), без реализации и состояния; класс может реализовывать много интерфейсов. Абстрактный класс может содержать и абстрактные методы, и готовую реализацию, свойства, конструктор, но наследоваться можно только от одного класса. Интерфейс выбирают, когда нужен «контракт» для разных, не связанных между собой классов; абстрактный класс — когда у семейства близких сущностей есть общий код и состояние.

**4. Можно ли создать объект абстрактного класса? Можно ли объявить абстрактное свойство?**
Нет, `new` для абстрактного класса вызывает ошибку; создавать можно только объекты наследников. Абстрактными в PHP могут быть только методы, свойства абстрактными быть не могут (обычно используют абстрактные геттеры или конструктор абстрактного класса).

**5. Чем static-свойство отличается от обычного? Как обратиться?**
Обычное свойство принадлежит конкретному объекту (у каждого экземпляра своё значение). Статическое принадлежит классу и общее для всех экземпляров. Внутри класса: `self::$count` (или `static::$count`), снаружи — `ИмяКласса::$count` (если свойство не private/protected).

**6. Что делает `readonly` и какие ограничения накладывает?**
Свойство `readonly` (PHP 8.1+) можно инициализировать только один раз, и только из области видимости самого класса (обычно в конструкторе); затем оно доступно только для чтения — повторное присваивание вызывает `Error`. Ограничения: свойство обязано быть типизированным, не может иметь значения по умолчанию и не может быть статическим.
